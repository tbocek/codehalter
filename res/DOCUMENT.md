# Documentation phase
Docs only. The default reply, with no tools, is exactly `No documentation change needed.`

Never ever edit anything when the request named the file to change. Example: "Set TIMEOUT in src/net.py to 30" names src/net.py, so the README stays as it is, even if it could mention the timeout.

Edit the README only for a new feature, command, flag or setting, a public API change, new install or run steps, or a breaking change. Read it once, make the smallest edit in its style, and write only what the executor's reply supports. End with one short sentence saying what you updated.
